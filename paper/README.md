# A Prior-Odds Adjustment for the Probability of Direction in Multiple Testing

This repository contains the manuscript source and everything needed to reproduce its simulations, figures, and worked example. 

## Contents

| Path | What it is |
|---|---|
| `manuscript.qmd` | Manuscript source (Quarto, [apaquarto](https://github.com/wjschne/apaquarto) format) |
| `manuscript.pdf` / `manuscript.html` | Rendered outputs |
| `bibliography.bib` | References |
| `apa.csl` | APA citation style |
| `_extensions/wjschne/` | apaquarto Quarto extension |
| `script/simulation.R` | Main simulation study (misspecification grid) → `script/output/sim_pi0.rda` |
| `script/results.R` | Computes FDR / FWER / power per cell from the raw simulation → `script/output/df_pi0.rda` |
| `script/compare_proc_joint.R` | Comparison of the three rules (`pd.adjust()`, `joint()`, `joint(interval = TRUE)`) → `script/output/df_compare.rda` |
| `script/utl.R` | Helper functions (analytical normal–normal posterior, metric computation) |
| `script/example/example-analysis.r` | Worked example: Stroop data (`afex::stroop`, Study 1), multilevel Lognormal model in `brms` |
| `script/example/mod_rt.rda` | The fitted `brms` model used in the manuscript |
| `script/output/*.rda` | Saved simulation results loaded by the manuscript |
| `_freeze/`, `manuscript_cache/`, `manuscript_files/` | Generated by Quarto/knitr (safe to delete; regenerated on render) |


### R packages used

- Manuscript chunks: `multibayes`, `dplyr`, `tidyr`, `ggplot2`, `MASS`, `mvtnorm`, `tibble`, `patchwork`, `scales`, `kableExtra`, `shape`
- Simulation: `furrr`, `purrr` (plus the above)
- Worked example: `afex` (data), `brms` (model)
