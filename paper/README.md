# A Prior-Odds Adjustment for the Probability of Direction in Multiple Testing

This folder contains the manuscript source and everything needed to reproduce its simulations, figures, and worked example.

## Contents

| Path | What it is |
|---|---|
| `manuscript_v2.qmd` | Manuscript source (Quarto, [apaquarto](https://github.com/wjschne/apaquarto) format) |
| `manuscript_v2.pdf` | Rendered manuscript |
| `supplement.qmd` / `supplement.pdf` | Supplementary Material (Figures S1 and S2, family-wise error rate) |
| `bibliography.bib` | References |
| `apa.csl` | APA citation style |
| `_extensions/wjschne/` | apaquarto Quarto extension |
| `script/simulation.R` | Simulation study (normal model with known covariance, independent or correlated parameters), writes `script/output/sim.rda` |
| `script/results.R` | FDR, FWER, and power of every condition from `sim.rda`, writes `script/output/df_pi0.rda`, `df_h0.rda`, and `df_compare.rda` |
| `script/utl.R` | Functions used by both scripts (multivariate normal posterior, simulation of one condition, error rates and power) |
| `script/example/example-analysis.r` | Worked example, Stroop data (`afex::stroop`, Study 1) with a multilevel lognormal model in `brms`, writes `script/example/mod_rt.rda` |
| `script/example/mod_rt.rda` | The fitted `brms` model used in the manuscript |
| `script/output/*.rda` | Saved simulation results loaded by the manuscript and the supplement |
| `_freeze/`, `manuscript_v2_cache/`, `manuscript_v2_files/` | Generated by Quarto and knitr, regenerated on render |



## R packages used

- Manuscript: `multibayes`, `dplyr`, `tidyr`, `ggplot2`, `MASS`, `mvtnorm`, `tibble`, `patchwork`, `scales`, `kableExtra`, `shape`, `brms` (to read the fitted model)
- Simulation: `furrr`, `purrr`, `MASS`, `multibayes`
- Worked example: `afex` (data), `brms` (model), `dplyr`
